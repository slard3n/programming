# Лабораторна робота №2

## Тема
Арифметичні вирази, форматування виводу.

## Завдання

1. Обчислити вартість одного квадратного метра житлової площі будинку.
2. Визначити відстані між туристичними об'єктами та повний шлях.

## Результати виконання

### Завдання 1

- Загальна площа будинку: 3000.00 м²
- Житлова площа: 2175.00 м²
- Вартість 1 м² житлової площі: 68.97 грн

### Завдання 2

Масштаб: 1 см = 0.250 км

Відстані на карті:
- 1: 1.500 см
- 2: 2.300 см
- 3: 5.900 см
- 4: 4.000 см

Відстані між об'єктами:
- 1: 0.375 км
- 2: 0.575 км
- 3: 1.475 км
- 4: 1.000 км

Повний шлях: 3.4 км

## Висновок

У ході лабораторної роботи було отримано навички використання арифметичних виразів та форматування виводу результатів у C++.
