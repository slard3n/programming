# Лабораторна робота №2

## Тема
Ввід даних у програму, інтерактивні і неінтерактивні програми.

## Завдання

1. Визначити розхід бензину автомобіля в км на літр.
2. Знайти середньозважене значення трьох екзаменаційних оцінок студента.

## Результати виконання

### Завдання 1

- Загальна кількість бензину: 46.70 л
- Пройдено: 1442.50 км
- Розхід бензину: 30.89 км/л

### Завдання 2

Оцінки та вагові коефіцієнти:
- 90 — 0.30
- 85 — 0.25
- 78 — 0.45

Середньозважене значення оцінки: 83.35

## Висновок

У ході лабораторної роботи було отримано навички введення даних з клавіатури, використання інтерактивного вводу та форматування дійсних чисел у C++.
